# カズクエ 本番プレイスルー・チェックリスト (KQ-42)

> main へ push すると GitHub Actions がビルドして GitHub Pages に配信する。
> 配信後にこの表を上から順に確認する。自動化できるものは E2E (`.github/workflows/e2e.yml`)
> が担うので、ここにあるのは **人が実機で見る項目** だけ。

対象 URL: `https://<user>.github.io/kids-stady/apps/kazu-quest/`
環境: iPad (横持ち・Safari)。PC の Chrome でも同じ順で確認できる。

## 1. 起動〜プロフィール

- [ ] トップページ (`/kids-stady/`) のカードからカズクエが開く
- [ ] 「だれが あそぶ?」でプロフィール一覧が出る (他アプリで作ったプロフィールも見える)
- [ ] 「あたらしく つくる」で名前+アバターを作れる。「けす」は2段階確認
- [ ] タイトルメニュー: セーブなし → 「はじめから」「せいせき」。セーブあり → 「つづきから」が先頭
- [ ] 「はじめから」→「やめる」でセーブが消えない

## 2. 章1 の最初の10分

- [ ] 母の会話 → 王都 → 王に謁見 → まなびやで「とっくんしてから テストする?」が出る
- [ ] とっくんで「ヒント」ボタンが出て、くりさがりでは さくらんぼ図が描かれる
- [ ] 習得テストは3択 (章1〜2) / テンキー (章3以降)
- [ ] 戦闘で間違えると勝利後に「まちがいノート」が出る。メニューの「ノート」タブで読み返せる
- [ ] ほこらで「ふくしゅうする?」→ 10問 → ひらめきメダル
- [ ] 王都のクイズずき・とけい塔・メダルしゅうしゅうかが動く

## 3. 各章の冒頭に飛んで確認する (本番では `?map=` が無効)

本番ビルドではデバッグ起動 (`?map=`) が無効なので、ブラウザのコンソールから
デバッグフックを使う (Safari: 設定 → 詳細 → Web インスペクタ):

```js
__KAZUQUEST_DEBUG__.advanceToChapter(3)   // 章3の開始位置へ (仲間も加入済みにする)
__KAZUQUEST_DEBUG__.grantLevel(20)        // パーティ全員を Lv20
__KAZUQUEST_DEBUG__.warp("ch6-zerom-throne", "entrance")
```

- [ ] 章2〜6 の開始町で、店・宿・まなびや・ほこら・おだいの けいじばん が開く
- [ ] ボス部屋前の たてふだ に「すいしょう Lv N」と いまの Lv が出る
- [ ] 章6 ゼロム撃破 → エンディング (数晶6つ → ぼうけんのまとめ → おしまい) → タイトル
- [ ] クリア後、ホシオキのほこらで「ムゲンのらせんに いどむ?」が出る

## 4. 音・向き・性能

- [ ] 最初のタップ後に効果音が鳴る。マップに入ると BGM、戦闘で曲が変わる
- [ ] メニュー「つよさ」タブの「おと: オン/オフ」で止まる・戻る
- [ ] 縦持ちで「iPad を よこむきに してね」が全画面に出て、横に戻すと消える
- [ ] `?debug=1` を付けて左上の FPS を見る。ワールドマップで常時 50 以上
  (詳細は [kazu-quest-perf.md](kazu-quest-perf.md))

## 5. データ

- [ ] リロードしても進行・習得呪文・ノート・おと設定が残る (`kidsStudy.kazuQuest.profileData.<id>`)
- [ ] ハブページの せいせき画面にカズクエの解答 (`kq_` 接頭辞) が反映される
- [ ] メニュー「せいせき」タブに学年別の帯グラフ・にがて3単元・14日のグラフが出る
