# カズクエ 出題の段階 (LP-02)

`generate(skillId, rng, opts?: { level?: 1 | 2 | 3 })` の `level` ごとに、小1〜小3
(20単元) の値域・出題形式がどう変わるかの一覧。`level` を省略 (または `undefined`)
した場合は **Lv2 と同じ出題** になる — 既存のシード固定テストが壊れないよう、
Lv2 の分岐は元の実装と完全に同じ乱数消費・同じ値域にしてある。

呼び出し側の既定 (`src/components/MathPromptPanel.tsx` の `levelForContext`):

| context | level |
|---|---|
| battle (戦闘) | 2 |
| drill (おだい・クイズ扉・フィールド回復呪文・レビュークエストなど、時間無制限のクイズ全般) | 3 |
| test / practice / field | 2 (既定のまま。れんしゅうの Lv1→3 段階出題は LP-09 で対応) |

実装: `src/lib/curriculum/grade1.ts` / `grade2.ts` / `grade3.ts`。
小4〜小6 (`grade4.ts`〜`grade6.ts`) は本タスクのスコープ外 (LP-02b で同形対応)。

## 小1 (grade1.ts)

| skillId | Lv1 (やさしい) | Lv2 (現行 = 省略時) | Lv3 (むずかしい) |
|---|---|---|---|
| g1_count | 3〜5こ を かぞえる | 3〜9こ を かぞえる (現行) | 6〜15こ を かぞえる |
| g1_compare | 1〜10 の 2数比較 | 1〜20 の 2数比較 (現行) | 1〜50 の 2数比較 |
| g1_add_nc | 1〜4 の たしざん (和≤5) | 1〜8 の たしざん・和≤9 (現行) | 3〜8 の たしざん・和≤9 (※注1) |
| g1_add_carry | `9 + x` の形のみ (x=2〜6) | `a+b` (a,b=2〜9)・くり上がり必須 (現行) | 十の位つき 2桁+1桁 のくり上がり (例: 37+8) |
| g1_sub_nc | 3〜5 からの ひきざん | 3〜9 からの ひきざん (現行) | 十の位つき 2桁-1桁 (くり下がりなし) |
| g1_sub_borrow | 11〜13 からの くり下がり | 11〜18 からの くり下がり (現行) | 十の位を一般化した くり下がり (例: 53-8) |

※注1: g1_add_nc は「くり上がりなし・一けた+一けた」の性質上、和の上限は Lv2 の
時点ですでに 9 (最大)。Lv3 は上限を広げられないため、たされる数・たす数の
最小値を引き上げて 9 に近い組み合わせ (むずかしい暗算) だけを出すことで
難度を上げている。`tests/curriculum.test.ts` では Lv3 の最大値が Lv2 と
**同じ** になることを許容し、その理由をコメントで明記した。

## 小2 (grade2.ts)

| skillId | Lv1 | Lv2 (現行 = 省略時) | Lv3 |
|---|---|---|---|
| g2_kuku | 2, 5 の だんのみ | 1〜9 の だんから ランダム (現行) | 7, 8, 9 の だんのみ (※注2) |
| g2_add_column | 2桁 (10〜49) どうしの たし算ひっ算 | 2桁 (10〜89) どうしの たし算ひっ算 (現行) | 3桁 (100〜899) どうしの たし算ひっ算 |
| g2_sub_column | 2桁 (20〜49 引く 10〜) の ひき算ひっ算 | 2桁 (20〜99 引く 10〜) の ひき算ひっ算 (現行) | 3桁 (200〜999 引く 100〜) の ひき算ひっ算 |
| g2_length | cm は 2〜5 / cm+mm は 1〜5 | cm は 2〜9 / cm+mm は 1〜9 (現行) | cm は 10〜99 (2桁cm) |
| g2_volume | L は 2〜5 / L+dL は 1〜5 | L は 2〜9 / L+dL は 1〜9 (現行) | L は 10〜20 (2桁L) |
| g2_time | じ:1〜5起点・12までの加算/1〜2じかん換算/10,20,30ぷん | じ:1〜9起点・12までの加算/1〜3じかん換算/10〜50ぷん (現行) | じ:正午をまたぐ加算 (最大24)/1〜6じかん換算/5きざみのぷん |

※注2: g2_kuku の Lv2 (現行) はすでに全段 (1〜9) からランダムに出題するため、
最大値 (9×9=81) は Lv2 の時点で到達済み。Lv3 (7,8,9の段) はその最大値と
**同じ** 81 になり得るが、「せまい段の中で むずかしい九九ばかり出る」という
体感難度の違いを優先した。

## 小3 (grade3.ts)

| skillId | Lv1 | Lv2 (現行 = 省略時) | Lv3 |
|---|---|---|---|
| g3_div | わる数 2〜9・商 2〜5 (九九のやさしい範囲) | わる数 2〜9・商 2〜9・わりきれる (現行) | わる数 2〜9・商 0〜15 (0わり・九九を超える商) |
| g3_div_remainder | わる数 3〜5・商 2〜5 | わる数 3〜9・商 2〜9 (現行) | わる数 3〜9・商 2〜20 (わられる数が大きい) |
| g3_mul_column | 2桁 (11〜44程度) × 1桁 (2〜4) | 2桁 × 1桁 (2〜9) のひっ算 (現行) | 3桁 × 1桁 (2〜9) のひっ算 |
| g3_big_number | 万の位 こ数 2〜5 / 千の位 11〜30 | 万の位 こ数 2〜9 / 千の位 11〜99 (現行) | 万の位 こ数 10〜99 / 千の位 100〜999 (十万の位まで) |
| g3_decimal | 0.1〜0.5 どうしの たしひき | 0.2〜1.2 どうしの たしひき (現行) | 2.0〜12.0 どうしの たしひき (2桁の0.1きざみ) |
| g3_fraction | 単位分数 (1/2, 1/3) の読み | 同分母の たし算・大小くらべ (現行) | 同分母の たしひき (くり上がって1になる形も含む) |
| g3_weight | kg 2〜4 / kg+g は kg1〜3,g100〜400 | kg 2〜9 / kg+g は kg1〜9,g100〜900 (現行) | kg 10〜90 (2桁kg) |
| g3_circle | 半径・直径 2〜6cm | 半径・直径 2〜12cm (現行) | 半径・直径 2〜30cm |

g3_fraction は Lv1〜3 で「読み → 大小くらべ/たし算 → たしひき」と出題の
**種類そのもの** が変わる単元 (単純な値域拡大ではない) ため、
`tests/curriculum.test.ts` の最大値比較チェックはこの単元だけ対象外にし、
その理由をコメントで明記した。同様に g3_div_remainder は「あまり」自体の
最大値が わる数-1 で頭打ちになるため、値域比較には わられる数 (`p.a`) を
代わりに使っている。
